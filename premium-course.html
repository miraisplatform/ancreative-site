─ ABOUT THIS COURSE
なぜ、選考が
必要なのか。

このコースを担当するのは、80社以上の設立に関わってきた外部講師です。一般的な講座とは異なり、決まった人数に対して、深く、個別に向き合う形で指導が行われます。だからこそ、本気で事業に向き合う方に、限られた時間とリソースを使いたいと考えています。受講には、面談3回による選考があります。

選考プロセス

事前面談を3回実施し、現在の状況・本気度・相性を確認させていただきます。選考は「ふるい落とす」ためではなく、「本当に向き合うべき相手か」を双方で見極めるための時間です。

─ SUPPORT AREA
  • 起業（会社等）だけでなく、芸術、美術、または美容師、パティシエ、IT関連等の技術職での独立
  • 自分の得意なことを活かしたフリーランス
  • イベントの主催者、団体の立ち上げ
  • スクールや各種教室の運営など

個人または小規模で始めたい人に対して、それぞれの段階に応じて指導、サポート、後方支援などを行います。

─ PHASE 01
// Class F

アイデアがまだない方へ。
型を知り、自分の種を見つける。

独立・起業に興味はあるけれど、何から始めればいいかわからない方のためのクラスです。アイデアは何もないところから降ってくるものではなく、いくつかの型・カテゴリを知ることで見つけ方が変わります。起業の代表的なパターンを学んだうえで、自分自身の興味・経験・違和感を掘り下げ、自分だけのアイデアとして言語化していきます。

到達ゴール
  • 起業の代表的なパターン・カテゴリを理解する
  • 自分の興味・経験から、起業アイデアの種を見つけられるようになる
  • アイデアを、人に説明できる形に言語化できるようになる
  • 次の実働クラスに進むための土台ができる
カリキュラム
STEP1起業の型を知る

起業の代表的なパターン・カテゴリを、実例を通して学びます。

STEP2自分の興味・経験を掘り下げる

好きなこと、経験、違和感を整理し、アイデアの種を見つけます。

STEP3アイデアを言語化する

見つけた種を、講師のフィードバックを受けながら言葉・形に落とし込みます。

※3ヶ月を通して3ステップを進めます。

対象者・条件
  • 18歳以上（できるだけ若い年齢を推奨）
  • アイデアがぼんやりとしている、または何も思いついていない方
  • 事前面談（3回）での選考を通過した方
概要
期間3ヶ月
回数週1回・月4回／1回120分
形式対面のみ
月30,000円（＋税）
─ PHASE 02
// Class S

アイデアが固まった方へ。
事業を、実際に動かす。

起業の種クラスなどでアイデアが固まった方が、実際に動き出すためのクラスです。事業計画の立て方、お金の流れの設計、最初のお客さんをどう見つけるかという集客・営業まで、実務に直結する内容を、手を動かしながら学んでいきます。進むスピードは人によって異なり、3ヶ月で一区切りつく方もいれば、もう少し時間をかける方もいます。

到達ゴール
  • 自分の事業の計画を、具体的な形に組み立てられるようになる
  • 事業に必要なお金の流れを把握し、管理できるようになる
  • 最初のお客さんに向けた営業・集客が自分でできるようになる
  • 実際に事業を動かし始める段階に立てる
カリキュラム
1ヶ月目事業計画の設計

誰に、何を、どう提供するのかを明確にし、具体的な事業計画として組み立てます。

2ヶ月目お金の流れ・財務の基礎

必要な資金、収支の見通しなど財務の基礎を学び、自分の事業に当てはめます。

3ヶ月目集客・営業の実践

最初のお客さんをどう見つけるか、実際の営業・集客の方法を学び実践します。

※進捗に応じて、3ヶ月以降も継続して受講いただけます。

対象者・条件
  • 18歳以上（できるだけ若い年齢を推奨）
  • 起業のアイデアがすでに固まっている方
  • 事前面談（3回）での選考を通過した方
概要
期間最低3ヶ月（進捗により継続あり）
回数週1回・月4回／1回120分
形式対面のみ
月50,000円（＋税）
─ PHASE 03
// Class X

すでに事業を持つ方へ。
継続的な経営の相談相手。

自分のビジネスをすでに動かしている方を対象とした、月額制のコンサルティングクラスです。決まったカリキュラムに沿って進む授業ではなく、その時々の事業の課題や状況に合わせて、内容を組み立てていきます。経営判断に迷ったとき、一人で抱え込まずに相談できる相手として、継続的に事業に向き合います。

到達ゴール
  • 経営上の判断に、一人で悩まず相談しながら進められるようになる
  • 事業の課題を継続的に整理し、改善していけるようになる
  • 自分の事業を、より安定的に成長させていけるようになる
カリキュラム

カリキュラムは固定せず、受講者の事業状況に応じて個別に設計します。一般的には、事業の現状確認・課題の整理・打ち手の検討・実行支援というサイクルを、継続的に繰り返していく形になります。

対象者・条件
  • 18歳以上（できるだけ若い年齢を推奨）
  • すでに自分のビジネスを運営している、または運営を始めている方
  • 経営上の相談相手を継続的に持ちたい方
  • 事前面談（3回）での選考を通過した方
概要
期間個別の契約による（人により異なる）
回数週1回まで対応可能
形式対面のみ
条件により変動

※価格はコンサルの深度や事業規模に応じて変動します。事業内容により応相談。
